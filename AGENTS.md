# Working in on-events

Use Node 24 and run `npm ci` followed by `npm run check`. See [CONTRIBUTING.md](./CONTRIBUTING.md) for the listener ownership contract, focused test commands, and the release procedure.

- Edit runtime code in `src/on-events.js` and declarations in `src/on-events.d.ts`. Keep event registration and disposal in the shared primitives described in the contributor guide.
- `Testing/` contains the DOM, native Node, TypeScript, example, and Closure Compiler checks. The full check builds and exercises both runtime entries.
- `dist/` is generated by `npm run build`. Regenerate `compiler/properties.json` and `compiler/closure.externs.js` with `npm run compiler:generate` when the public type surface or TypeScript dependency changes.
- Keep application recipes in `examples/`. Record consumer-facing changes in `CHANGELOG.md`.
